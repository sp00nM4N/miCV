# Sebastian Moya | Landing CV

Landing profesional bilingue desarrollada con React, Vite, TailwindCSS y Framer Motion para posicionar un perfil senior de Product Owner en Oil & Gas, con background tecnico y evolucion hacia Data Analytics / Machine Learning.

## Stack

- React 18
- Vite
- TailwindCSS
- Framer Motion
- Lucide React

## Features

- Landing one-page bilingue (`ES/EN`)
- Hero con resumen profesional y acciones para compartir
- Secciones de experiencia, capacidades, evolucion, educacion, enfoque y contacto
- Diseno minimalista con interacciones sutiles
- Preparado para uso local en red

## Scripts

```bash
npm install
npm run dev
npm run dev:network
npm run build
npm run preview
npm run preview:network
```

## Desarrollo en red local

- `npm run dev:network`
- Abrir desde otro dispositivo en `http://TU_IP_LOCAL:5173`

## Build de produccion

```bash
npm run build
npm run preview:network
```
